# Apporteurs

Vos intermédiaires figurent dans une **arborescence** : un apporteur principal, en dessous ses bureaux, et en dessous les collaborateurs individuels. Vous voyez ainsi immédiatement qui relève de qui.

## Ouvrir l'écran

Dans la barre latérale, cliquez sur **CRM**, puis sur **Apporteurs**.

Cliquez sur le triangle devant une ligne pour déplier ou replier un niveau. Les largeurs de colonnes que vous réglez sont conservées pour la fois suivante.

## La fiche

Double-cliquez sur une ligne pour ouvrir la fiche. Elle comporte deux onglets.

### Onglet Général

Identité, coordonnées, adresse et **langue des documents** — cette dernière détermine dans quelle langue cet apporteur reçoit ses documents et ses e-mails.

!!! tip "Récupérer automatiquement les données d'entreprise"
    Si vous renseignez le **numéro de TVA**, CreditSoft récupère le nom, la forme juridique et l'adresse directement depuis la Banque-Carrefour des Entreprises.

Y figure également le **numéro FSMA**, avec une case indiquant si l'inscription est en ordre.

### Onglet Commission

L'accord de commission standard pour cet apporteur. Il est proposé sur les nouveaux dossiers ; vous pouvez encore y déroger dossier par dossier.

## Donner accès au portail

Le bouton **Portail** permet de donner à un apporteur son propre accès. Il y voit :

- **Mes dossiers** — les dossiers qu'il a apportés, avec leur statut.
- **Mes commissions** — ce qui est comptabilisé pour lui.

Sur la fiche, vous déterminez pour chaque apporteur s'il voit l'onglet des commissions et celui des documents. Vous pouvez ainsi ouvrir le portail sans montrer d'emblée tous les chiffres.

!!! warning "Un apporteur ne voit que ses propres données"
    Le portail est cloisonné par apporteur. Un bureau voit les dossiers de ses propres collaborateurs, mais jamais ceux d'un autre bureau.
