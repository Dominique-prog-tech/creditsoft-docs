# Groupes

Les groupes sont des étiquettes libres pour classer les **apporteurs** — par exemple par région ou par segment. Cet écran gère la liste des groupes ; l'affectation elle-même se fait sur la fiche de l'apporteur.

## Ouvrir l'écran

Dans la barre latérale, cliquez sur **Groupes**.

## La liste

Le tableau affiche le **nom** de chaque groupe.

- **Rechercher** — utilisez le champ de recherche.
- **Exporter** — exportez la liste via Excel ou CSV.
- **Nouveau / modifier** — cliquez sur **Nouveau**, ou **double-cliquez** une ligne pour la modifier.
- **Supprimer** — un groupe est **archivé** (suppression douce), pas définitivement effacé.

## Ajouter ou modifier un groupe

Un groupe n'a qu'un **nom**. Saisissez-le et cliquez sur **Enregistrer**. La suppression se fait dans le même écran d'édition.
