# Assureurs

Les assureurs sont les compagnies pour l'**assurance solde restant dû (ASRD)** liée à un dossier de crédit. CreditSoft en conserve ici les données de base sous forme de **liste de choix** ; vous sélectionnez un assureur sur le dossier.

## Ouvrir l'écran

Dans la barre latérale, cliquez sur **Assureurs**.

## La liste

![L'écran Assureurs dans CreditSoft : une liste de compagnies d'assurance avec les colonnes nom, commune, téléphone, e-mail et site web, avec en haut les boutons Nouveau et Exporter ainsi qu'un champ de recherche.](../images/verzekeraars-lijst-fr.png "Aperçu des assureurs pour l'assurance solde restant dû")

Le tableau affiche par assureur : **nom**, **commune**, **téléphone**, **e-mail** et **site web**.

- **Rechercher** — utilisez le champ de recherche pour chercher dans toutes les colonnes à la fois.
- **Choisir les colonnes** — affichez ou masquez des colonnes ; votre choix est mémorisé.
- **Exporter** — exportez la liste via Excel ou CSV.
- **Nouveau / modifier** — cliquez sur **Nouveau**, ou **double-cliquez** une ligne pour ouvrir l'écran d'édition.
- **Supprimer** — la suppression se fait dans l'écran d'édition ; un assureur est **archivé** (suppression douce), pas définitivement effacé.

### Journal

À droite de l'écran se trouve le tiroir **Journal**. Sélectionnez un assureur et ouvrez-le : vous y tenez, par
compagnie, vos **tâches, notes, pièces jointes et courriers**, ainsi que le **journal** des modifications.

## Ajouter ou modifier un assureur

![L'écran d'édition d'un assureur : nom AXA, adresse Zuidlaan 47 à 2800 Mechelen, pays Belgique, téléphone, e-mail et site web, numéro d'institution VZ8278, la langue des documents sur Néerlandais, un champ pour les remarques et en bas le bouton pour choisir un logo.](../images/verzekeraars-bewerken-fr.png "Compléter les données d'un assureur")

Le formulaire contient les données essentielles :

- **Nom** (obligatoire)
- **Adresse** — rue, numéro, boîte, code postal, commune, pays. Saisissez un **code postal** dans le champ de recherche et la **commune** se remplit automatiquement ; le pays se choisit dans la liste.
- **Contact** — téléphone, fax, e-mail, site web
- **Numéro d'institution**
- **Langue des documents** — la langue dans laquelle vous correspondez avec cette compagnie (néerlandais ou français). Elle détermine la langue des modèles d'e-mail et des documents établis pour cet assureur.
- **Remarques**
- **Logo** — chargez une image ; elle apparaît notamment sur les impressions

Cliquez sur **Enregistrer** pour sauvegarder. Une **adresse e-mail** renseignée est vérifiée lors de l'enregistrement.
