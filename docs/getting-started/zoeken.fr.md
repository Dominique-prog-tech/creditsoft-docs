# Rechercher depuis n'importe quel écran

En haut à droite se trouve une **loupe**. Elle vous permet de rechercher depuis n'importe quel écran, sans
devoir d'abord ouvrir la bonne liste. Raccourci : **Ctrl + K** (sur Mac **⌘ + K**).

Saisissez un nom ou un numéro. Les résultats apparaissent au fur et à mesure de la frappe, regroupés par
type :

- **Relations** — par nom
- **Dossiers de crédit** — par numéro de dossier *et* par le nom du demandeur
- **Apporteurs** — par nom
- **Professionnels** — par nom
- **Prospects** — par nom

Cliquez sur un résultat pour vous y rendre directement.

## Les dossiers se retrouvent aussi par le nom du client

Si vous saisissez un nom, cette personne apparaît **deux fois** : une fois sous *Relations*, et une fois sous
*Dossiers de crédit* pour chaque dossier dont elle est demandeur.

C'est voulu. Vous connaissez généralement le client, rarement le numéro de dossier ; vous ne devez donc pas
d'abord ouvrir sa fiche pour accéder à ses dossiers. Les deux types de résultats vous mènent d'ailleurs à des
endroits différents : l'un vers la fiche de la personne, l'autre vers le dossier lui-même.

## Vous ne voyez que ce à quoi vous avez droit

Chaque type suit le droit de son propre écran. Si vous n'êtes pas autorisé à consulter les dossiers de
crédit, ce groupe ne s'affiche pas — même si le nom que vous saisissez correspond bien à un dossier.

Si un type n'apparaît pas alors que vous savez qu'il devrait y avoir des résultats, il s'agit donc le plus
souvent d'une question de droits. Renseignez-vous auprès du responsable de votre bureau.

!!! tip "La recherche dans une liste reste possible"
    La loupe en haut recherche dans **tous** les types à la fois. Pour rechercher ou filtrer au sein d'une
    seule liste — par exemple tous les dossiers ayant un statut donné — utilisez le champ de recherche et les
    filtres de cette liste. Voir [Travailler avec les listes](lijsten.fr.md).
