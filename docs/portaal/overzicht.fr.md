# Aperçu

L'écran d'accueil du portail. Il montre d'un coup d'œil comment se déroule l'année.

## Ouvrir l'écran

Dans le portail, cliquez en haut sur **Aperçu**.

## Les quatre chiffres

Quatre tuiles figurent en haut.

- **Crédits conclus** — combien de crédits sont devenus définitifs cette année, et pour quel montant total.
- **En cours** — les dossiers dont le crédit n'est pas encore définitif, avec le montant demandé. Ce chiffre
  porte sur aujourd'hui, pas sur une année.
- **Commission** — ce qui est comptabilisé en commission cette année. Cette tuile n'apparaît que si votre
  bureau affiche les commissions dans le portail.
- **Bureaux dans votre aperçu** — sur combien d'apporteurs portent les chiffres ci-dessus. S'il y a **1**, ce
  sont vos propres dossiers.

!!! info "Quand un crédit compte-t-il ?"
    Un crédit compte pour l'année où il est devenu **définitif**, pas pour celle de la demande. Un dossier
    sans cette date figure donc toujours sous *En cours*, quelle que soit son ancienneté.

Sous les tuiles, une phrase indique sur combien de bureaux portent les chiffres. Si vous voyez les dossiers
de vos collaborateurs mais pas leur commission, cela y est précisé — vous savez ainsi toujours ce que vous
avez, et ce que vous n'avez pas, sous les yeux.

## Choisir l'année

En haut à droite, deux flèches encadrent l'année. Elles permettent de remonter dans le temps ; vous ne
pouvez pas aller au-delà de l'année en cours.

Si vous n'avez encore rien conclu cette année, l'écran s'ouvre automatiquement sur la dernière année où
cela a été le cas. Vous ne regardez donc jamais un écran vide alors qu'il existe des chiffres.

## Le graphique

Une barre par mois, avec le montant des crédits conclus. Si rien n'a encore été conclu dans l'année
choisie, une phrase remplace le graphique vide.

## Derniers crédits conclus

En bas, les huit crédits les plus récents de l'année choisie, avec leur numéro de dossier, la date à
laquelle ils sont devenus définitifs et le montant. Cliquez sur un numéro pour ouvrir le dossier, ou à
droite sur **Tous les dossiers** pour la liste complète.
